## Sega 32X Application

The Sega 32X application for [webЯcade](https://www.webrcade.com) is an emulator for the [Sega 32X](https://en.wikipedia.org/wiki/32X) add-on for the Sega Genesis/Mega Drive.

## Documentation

The Sega 32X Application Documentation includes keyboard and gamepad control mappings, and details regarding the use of the emulator within a [webЯcade feed](https://docs.webrcade.com).
