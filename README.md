# webЯcade Applications: Sega 32X, Sega 32X CD Emulators

[![License](https://img.shields.io/badge/License-Apache%202.0-blue.svg)](https://opensource.org/licenses/Apache-2.0)

This repository contains [webЯcade](https://www.webrcade.com) applications for the following systems:

* [Sega 32X](#sega-32x)
* [Sega 32X CD](#sega-32x-cd)

The underlying emulator is a forked version of [Libretro PicoDrive](https://github.com/irixxxx/picodrive).

## Sega 32X

The Sega 32X application for [webЯcade](https://www.webrcade.com) is an emulator for the [Sega 32X](https://en.wikipedia.org/wiki/32X) add-on for the Sega Genesis/Mega Drive.

 <a href="https://play.webrcade.com">
  <img src="https://docs.webrcade.com/assets/images/apps/32x.png" width="90%">
 </a>
</p>

### Documentation

The [Sega 32X Application Documentation](https://docs.webrcade.com/apps/emulators/32x/) includes [keyboard](https://docs.webrcade.com/apps/emulators/32x/#keyboard) and [gamepad](https://docs.webrcade.com/apps/emulators/32x/#gamepad) control mappings, information related to [battery-backed SRAM](https://docs.webrcade.com/apps/emulators/32x/#battery-backed-sram) support, and details regarding the use of the emulator within a [webЯcade feed](https://docs.webrcade.com/apps/emulators/32x/#feed).

## Sega 32X CD

The Sega 32X CD application for [webЯcade](https://www.webrcade.com) is an emulator for Sega CD titles that require the [32X](https://en.wikipedia.org/wiki/32X) add-on, combining the Sega CD's CD-ROM drive with the 32X's enhanced graphics hardware.

<p align="center">
 <a href="https://play.webrcade.com">
  <img src="https://docs.webrcade.com/assets/images/apps/32xcd.png" width="90%">
 </a>
</p>

### Documentation

The [Sega 32X CD Application Documentation](https://docs.webrcade.com/apps/emulators/32xcd/) includes [control mappings](https://docs.webrcade.com/apps/emulators/32xcd/#controls) (shared with the Sega 32X application), information related to [RAM Cart and Backup RAM Storage](https://docs.webrcade.com/apps/emulators/32xcd/#ram-cart-and-backup-ram-storage) support, and details regarding the use of the emulator within a [webЯcade feed](https://docs.webrcade.com/apps/emulators/32xcd/#feed).
